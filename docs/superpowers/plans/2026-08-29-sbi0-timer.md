### Task 1: Timer SBI + S-mode ticks in `sbi0`

Replace `sbi0/src/main.rs` with the implementation that matches the spec (full file is the current crate plus the blocks below). Build `cargo build -p sbi0 --release --target riscv64imac-unknown-none-elf`. `check-sbi0.sh` must still pass; add `trap_s` to the nm checks.

Required behavior (do not skip):

- `enable_mtimer_clock`: `0x30000018`, clear EN, `div=319`, set EN.
- `write_mtimecmp`: 32-bit high=`0xffffffff`, then low, then high.
- `sbi_set_timer` (`a7=0`): write cmp, `csrc mip, STIP`, `csrs mie, MTIE`.
- Machine timer `(1<<63)|7`: `csrs mip, STIP`, `csrc mie, MTIE`; **no** `mepc+=4`.
- Ecall `mcause==9`: `mepc+=4` then dispatch; include `a7=0`.
- `enter_s_mode` sets `MPIE` so `MIE=1` after `mret`.
- `mideleg = 1<<5` only.
- S-mode: hello, `stvec=trap_s`, `sie.STIE`, set_timer(`rdtime()+200000`), `sstatus.SIE`, `wfi` loop; 5 ticks then shutdown.
- `\r\n` via putchar ecall only from S-mode.
